## Mis Proyectos de Python
En este repositorio estaré poniendo mis proyectos al aprender en Python, desarrollados para mi preparación para Ingeniería de Software.
## Proyectos
- **Contactos_simple.py** — Una agenda de contactos con funciones de agregar, mostrar, buscar, editar y eliminar. Guarda los datos en un archivo JSON.
- **Inicio.py** — Primer programa de práctica con input, condicionales y bucles.
- **Organizador.py** — Organizador de tareas con prioridades.
- **Progreso.py** — Programa de práctica con funciones.
## Tecnologías que uso
- Python 3
- JSON para los datos
- Git y GitHub
